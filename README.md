# archer

A terminal-based HTTP client built with Ratatui.

## Features

- Interactive HTTP request builder
- Support for GET, POST, PUT, DELETE, PATCH methods
- Request headers and body editing
- Real-time response display with status and timing
- Syntax highlighting for JSON responses

## Usage

### Keyboard Shortcuts

- `Ctrl+G` - Focus method input
- `Ctrl+U` - Focus URL input  
- `Ctrl+P` - Focus parameters editor
- `Ctrl+H` - Focus headers editor
- `Ctrl+R` - Focus request body editor
- `Ctrl+N` - **Make HTTP request** (shows response time and status on the right side)
- `Ctrl+K` - Toggle response panel
- `Ctrl+E` - Toggle collections explorer
- `Ctrl+C` - Quit application

### Making Requests

1. Enter the URL using `Ctrl+U`
2. Select HTTP method using `Ctrl+G` 
3. Add headers using `Ctrl+H` (format: `Header-Name: value`)
4. Add request body using `Ctrl+R` (for POST/PUT/PATCH)
5. Press `Ctrl+N` to execute the request
6. View response with `Ctrl+K` - status and response time appear right-aligned on the right side

## Building

```bash
cargo build --release
```

## Running

```bash
cargo run
```
